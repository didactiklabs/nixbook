# This documentation

This website is built with [VitePress](https://vitepress.dev) from the `docs/` directory, and deployed to **GitHub Pages** by GitHub Actions on every change to `main`.

## Run it locally

In the devenv shell (Node.js and pnpm come with it):

```bash
doc-dev       # dev server with hot reload: http://localhost:5173/nixbook/
doc-build     # production build into docs/.vitepress/dist
doc-preview   # serve the production build
```

## Layout

```
docs/
├── .vitepress/config.mts   site config: navigation, sidebar, search, base URL
├── public/                 static files (logo)
├── index.md                home page
├── guide/  installation/  machines/  system/  user/
├── desktop/  nixbook-shell/  packages/  development/
├── reference/options.md    includes MODULES.md
├── MODULES.md              generated by generate-docs (not a page itself)
├── generate-docs.nix       the generator
└── package.json, pnpm-lock.yaml
```

Two pages are generated from files maintained elsewhere — edit the source, not the page:

| Page                                 | Source                                                          |
| ------------------------------------ | --------------------------------------------------------------- |
| [Module options](/reference/options) | `docs/MODULES.md`, generated from the modules (`generate-docs`) |
| [Keybindings](/desktop/keybindings)  | `KEYBINDS.md` at the repository root                            |

## Adding a page

1. Create the Markdown file in the right section, e.g. `docs/system/my-feature.md`.
2. Add it to the `sidebar` (and `nav` if needed) in `docs/.vitepress/config.mts`.
3. Run `doc-build`: it fails on **dead links**, so broken internal links never reach the site.
4. Run `treefmt` (prettier formats the Markdown).

Pages can use VitePress features such as [custom containers](https://vitepress.dev/guide/markdown#custom-containers) (`::: tip`, `::: warning`) and frontmatter.

## Deployment

`.github/workflows/docs.yaml`:

- on a **pull request** touching `docs/`, `KEYBINDS.md` or the devenv files: builds the site (`devenv shell -- doc-build`) so problems show up in review;
- on **`main`**: builds and deploys `docs/.vitepress/dist` to GitHub Pages.

::: info One-time setup
In the repository's **Settings → Pages**, set **Source** to **GitHub Actions**. The site is then served at `https://didactiklabs.github.io/nixbook/`. To serve it from a custom domain, build with `DOCS_BASE=/` and add the domain in the Pages settings.
:::
